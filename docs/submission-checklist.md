# Veritas AI submission checklist

Based on the official [project submission requirements](https://highschoolhackathon.org/briefs) and [judging criteria](https://highschoolhackathon.org/judges), checked November 15, 2026. The linked Google Drive track-brief PDF could not be read in this session; check any additional instructions there before submitting.

## Included in the README

- Finance track and the existing team names.
- A concise explanation of the problem, implementation, additions, results, limitations and next steps.
- A live website link, notebook link and judge testing instructions.
- Separate descriptions of the notebook's saved IBM HI-Small benchmark and the website's synthetic teaching-model weights.
- Public/synthetic data provenance and prototype/not-financial-advice statement.
- Credits for IBM AMLworld, model frameworks, Nemotron/OpenRouter, OpenAI assistance, design tooling and application libraries.

## Finish before submitting

- Confirm the GitHub repository and website open without signing in. A public code link is required. Automated external checks here could not establish public accessibility.
- Use the README as the single write-up, or choose another supported write-up format in the form.
- Enter each teammate's full name, email and school in the form. Emails/schools are not published in the README.
- Add any other dataset, pretrained model, tutorial, starter notebook or AI tool that was used. If an official starter was used, link it and identify your additions; its use has not been confirmed here.
- The user confirmed Nemotron for extraction; verify the deployed `DOLOS_PDF_MODEL` agrees with the credited route.
- Supply the optional video link when ready. Keep it at most two minutes; use unlisted YouTube or Drive sharing that allows anyone with the link to view.
- Test all four live examples on both models after deploying this revision; network requests must return fresh scores rather than an unavailable-runtime error.
- Verify each submission link in an incognito window.
- Confirm every team member contributed, understands the work, and that the project satisfies the event's build-window and public/synthetic-data rules. Those declarations require the team's confirmation and have not been asserted on your behalf.

The official page permits one person to submit for the team and says the latest version submitted before the deadline is judged. This checklist does not submit the project.
