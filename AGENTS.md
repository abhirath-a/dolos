# Notebook language

Use ASD-STE100, Issue 9, for all English text in `dolos.ipynb`.
Apply this rule to headings, comments, notes, and output labels.

- Use short sentences and active voice.
- Use one term for each concept.
- Define technical terms in the notebook term list.
- Use no more than 20 words in each instruction sentence.
- Use no more than 25 words in each description sentence.
- Keep code names and model names unchanged.
- Do not change a result to improve a claim.
- Do not use saved baseline results as results for a new model.

Check the writing rules and the controlled dictionary when you change the text.
Do not claim formal language approval without a full review.

Reference: https://www.asd-ste100.org/
